<img width="1893" height="860" alt="image" src="https://github.com/user-attachments/assets/32592567-7e15-4d41-96d8-32c77803a1c6" /> <br>

Projeto desenvolvido e criado pelo Gustavo Campelo (WebHub).

Baseia-se em num site front-end personalizado pela ficção Stranger Things. O projeto tem o intuito de reforçar a aprendizagem das tecnologias HTML, CSS, JavaScript e a biblioteca GSAP.

O foco principal foi aprender novas ideias de criação de animações do GSAP. Irei descrever as animaçoes mais chamativas do site: foi criado um loader com o logo do Stranger Things, um efeito paralax do monstro ao mover a página para baixo, letras e imagens aparecendo/desaparecem a medida que avança com a pagina e no final da pagina foi feito um footer moderno que consiste num carrossel infinito.
